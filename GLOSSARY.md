# Task Management

A small application for keeping a list of tasks: creating them, marking them done, renaming them and deleting them.

## Language

**Task**:
A single piece of work someone wants to remember, identified by its name.
_Avoid_: Todo, item, ticket

**Priority**:
How pressing a Task is, chosen once when the Task is created: LOW, NORMAL or URGENT.
_Avoid_: Importance, severity

**Done**:
Whether the work a Task describes has been completed. A Task can be marked done and un-marked again.
_Avoid_: Completed, finished, closed

**Created**:
The moment a Task came into existence, recorded by the system, never supplied by a person.
_Avoid_: Creation date, timestamp
